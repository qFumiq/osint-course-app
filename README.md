# OSINT Практика

Локальное приложение с курсом по исследованию открытых источников. Работает на Windows в браузере. Интерфейс, уроки, учебные документы и заметки доступны без интернета; внешние задачи и сервисы открываются по ссылкам.

## Запуск на Windows

1. Установите Python 3.10 или новее, если его ещё нет.
2. Скачайте репозиторий, распакуйте и дважды нажмите **Start.cmd**.
3. Откроется `http://127.0.0.1:8765/`. Окно запуска оставьте открытым.

Другой способ: `python start.py`. Чтобы остановить приложение, нажмите Ctrl+C в окне запуска. Сервер принимает подключения только с этого компьютера и раздаёт только папку `app/`.

Для просмотра без Python можно открыть `app/index.html`. Сохранение данных при таком запуске зависит от политики браузера для локальных файлов; рекомендуемый запуск — через Start.cmd.

## Что работает

- Курс: 27 коротких уроков по OSINT, WEBINT, SOCMINT, IMINT, GEOINT, хронолокации, открытым данным об организациях, HUMINT и отчётности.
- Практикум: 14 доступных заданий, включая внешние задачи и шесть работ на оригинальном учебном наборе. Пять спецификаций будущих задач помечены как «Готовится».
- Вымышленный кейс «Свет и форма»: семь документов, четыре интервью, подсказки, отдельный разбор.
- Каталог 25 инструментов: поиск, категории и избранное.
- Сохранение решений, отметок прохождения и черновиков отчётов.
- Редактор отчёта с источниками, экспортом Markdown и печатью/PDF через браузер.
- Помощники: координаты и SHA-256 файла.
- Резервная копия прогресса и работ в JSON, восстановление через интерфейс.

Курс вводный. Свободные исследования не проходят автоматическую фактологическую экспертизу: ученик сопоставляет работу с разбором и рубрикой. Расширенные функции внешних сервисов могут требовать аккаунта или подписки; это отмечено в карточках.

## Данные

Работы сохраняются в локальном хранилище браузера. Очистка данных браузера удаляет их; периодически скачивайте резервную копию в разделе «Мои работы». Разные браузеры и порты используют раздельное хранилище. Учебные материалы вымышлены либо представлены ссылками на первоисточник. Исходная личная библиотека автора в репозиторий не включена.

## Разработка и проверка

Приложение не требует npm-пакетов. Node.js нужен только для проверок логики:

```text
npm test
npm run check
python -m unittest discover -s tests -p "test_*.py"
```

Дополнительная проверка интерфейса — `node tests/browser.cjs`. Она требует установленного Playwright и Microsoft Edge, использует отдельный временный профиль браузера и работает с уже запущенным приложением. Скриншоты проверки сохраняются в игнорируемой папке `tmp/browser-test/`. Основные проверки не требуют браузерных пакетов.

Данные курса собираются командой `python scripts/build_data.py` из `content/lessons.json` и учебных Markdown-файлов. Проверенный результат `app/data.js` включён в репозиторий, поэтому для запуска пересборка не нужна.

Структура: `app/` — интерфейс и логика; `content/` — исходные учебные материалы; `scripts/` — сборка данных; `tests/` — проверки; `start.py` — локальный запуск.
