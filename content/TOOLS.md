# Каталог инструментов курса

Дата проверки страниц и документации: 25 октября 2026 года. 25 позиций.

Проверка означает просмотр сайта, описания автора или официальной документации. Полные пользовательские сценарии, доступность из конкретной сети и интеграции пока не тестировались. Таблица описывает способ включения в будущую версию приложения; сейчас добавлены ссылки.

## Собственные функции приложения

Эти функции предлагаются к разработке и пока не реализованы:

1. Реестр источников с URL, датой доступа, копией и происхождением.
2. Матрица «утверждение → доказательство → ограничение».
3. Хронология с исходным временем и нормализованным часовым поясом.
4. Редактор отчёта и выгрузка текста вместе с источниками.
5. Сравнение двух изображений с собственными отметками поверх производной копии.
6. Перевод координат между десятичной и градусной записью.
7. SHA-256 локального файла с сохранением результата в реестре.

Для HUMINT основными помощниками будут план интервью, стенограмма, отметки согласия, время цитаты и таблица проверки свидетельств. Отдельный сервис для поиска людей этому разделу не нужен.

## Минимум полей карточки инструмента

ID; название; направление; задача; официальный URL; ссылка на документацию; тип «сайт / расширение / локальная программа / встроенная функция»; язык; известные требования доступа; ограничения; пример; связанные уроки и кейсы; дата проверки; уровень проверки «описание / ручной сценарий / интеграция»; сведения о лицензии при встраивании.
